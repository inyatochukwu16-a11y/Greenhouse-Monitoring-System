# Greenhouse Monitoring System

## Project Overview

The Greenhouse Monitoring System is a C++ console-based application designed to monitor and analyse environmental conditions within a greenhouse.

The program allows users to manually enter temperature and humidity readings, store the readings, calculate average values, identify the highest recorded temperature, and assess environmental conditions based on predefined thresholds.

This project serves as a software prototype for a future ESP32-based greenhouse monitoring system that will integrate physical sensors and display units.
